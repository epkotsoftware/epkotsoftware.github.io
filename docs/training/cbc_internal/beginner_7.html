読む前に
このページは2つの話でできています。前半（1〜2章）が float、後半（3〜5章）がセレクタです。
float は今から書くための技術ではありません。既存のサイトを直すときに読めるように、という位置づけです。そのつもりで気楽に読んでください。

1. floatで横に並べる

#5では display: flex; で横並びを作りました。float は、flexが登場する前に使われていたやり方です。

先に結論
これから新しく作るときは、float ではなく flex を使ってください。
ただ、世の中にある既存のサイトには float で組まれたものが山ほど残っています。読めないと直せないので、ここで押さえておきます。

何もしないと縦に積まれる

理解ポイント
float は「浮かべる」という意味の英単語です。名前のとおり、その要素だけを通常の並びから浮かせて、端に寄せます。
浮いた要素は縦に積む列から抜けるので、次の要素はそのすぐ横に来ます。3つとも浮かせたので、3つが横一列に並びました。

float: right で右に並ぶ

right にすると、右端から順に寄ります。並ぶ順番が逆に見えるところに注意してください。

float: left .box { float: left; }

補足
float: right の見本も、HTMLの書き順は「1・2・3」で同じです。それでも画面では右端から 1 → 2 → 3 の順に寄っていくので、見た目は「3・2・1」になります。
「右端から順に詰めていく」と考えると分かりやすいです。

2. floatの後始末 ― clearfix

float には厄介な副作用があります。ここが最大のつまずきどころです。

1章の見本について
1章では、点線の枠がきちんと箱を囲んでいました。実はあの見本には、これから説明する後始末をあらかじめ入れてあります。
入れないとどうなるのか、ここで見ていきます。

親の高さがなくなる

子要素が浮いてしまうと、親要素はその高さを知らないままになります。結果、親の高さが0になり、中身が外へはみ出したように見えます。

✕ floatあり・後始末なし <!-- HTML --> <div class="wrap"> /* CSS */ .box { float: left; }
1
2
この文章は親の外に書いてあります
○ clearfixあり <!-- HTML：クラスを1つ足す --> <div class="wrap clearfix"> /* CSS：これを追加 */ .clearfix:after { … }
1
2
この文章は親の外に書いてあります
注意
✕ の見本を見てください。黄色い親の枠が、箱の高さぶんだけ広がっていません。箱が枠からはみ出し、下の文章とも重なっています。
○ の見本は、親の枠がきちんと箱を囲み、下の文章も正しい位置にあります。この差を作っているのが clearfix です。

clearfixの中身

やっていることは、親の最後に空っぽの要素を1つ足して、そこで浮きを打ち切ることです。

style.css — Visual Studio Code
index.html
style.css
1 2 3 4 5
.clearfix:after {
  content: "";
  display: block;
  clear: both;
}
書いていること 意味
:after この要素のいちばん最後に、中身を1つ足す
content: ""; 足す中身は空っぽ（画面には何も出さない）
display: block; 足したものをブロックレベル要素にする
clear: both; 浮いているものの下まで下がる（ここが本体）
理解ポイント
clear: both; を持った空の要素が、浮いた箱たちの下に来ます。親はその要素までを自分の中身として数えるので、結果的に高さが戻ります。
使うときは、float した子を持つ親のほうに class="clearfix" を付けます。
なぜ「fix」なのか
clearfix は clear（打ち切る）と fix（直す）を合わせた呼び名です。CSSの正式な機能名ではなく、現場でそう呼ばれてきた通称です。
検索すると書き方がいくつも出てきますが、どれも狙いは同じ「親の高さを取り戻す」です。
コロンの数について
ここでは :after とコロン1つで書いています。じつはいまの正式な書き方はコロン2つの ::after です。
ただ clearfix は古くから1つで書かれてきたので、既存のサイトではほぼ1つで見かけます。どちらでも同じように動きますので、いまは気にしなくて大丈夫です。
::after そのものについては、4章でくわしく扱います。
ここまでのまとめ
float を使うと、必ずこの後始末がセットで必要になります。flex ならこの問題はそもそも起きません。
これが「新しく作るなら flex」と言われる理由のひとつです。

3. セレクタの種類

ここからは話が変わります。CSSの「どこに効かせるか」を書く部分、セレクタの話です。

#5でクラス（.box）を使いました。実は、要素の狙い方はほかにもたくさんあります。

呼び方 書き方 何を狙うか
クラスセレクタ .test class="test" が付いた要素
IDセレクタ #test id="test" が付いた要素
要素型セレクタ div　p　span　a そのタグ全部
全称セレクタ * すべての要素

クラスとIDの違い

どちらも「名前を付けて狙う」点は同じです。違いは同じ名前を何個に付けられるかです。

見方
次の2つの見本は、色が付くという結果だけ見れば同じです。違いが出るのはコードのほうなので、そちらを見比べてください。
クラスは2つの li に同じ名前を付けています。IDは1つにしか付けられません。
クラス（何回でも使える） <!-- HTML --> <li class="test">1つ目</li> <li class="test">2つ目</li> <li>3つ目</li> /* CSS */ .test { background: 黄色; }
  • 1つ目
  • 2つ目
  • 3つ目
ID（ページに1つだけ） <!-- HTML --> <li id="test">1つ目</li> <li>2つ目</li> <li>3つ目</li> /* CSS */ #test { background: 黄色; }
  • 1つ目
  • 2つ目
  • 3つ目
クラス ID
HTMLでの書き方 class="test" id="test"
CSSでの書き方 .test（ピリオド） #test（シャープ）
同じ名前を何個に付けられるか いくつでも 1ページに1つだけ
ここが違い
さきほどの見本で、クラスのほうは2つの li に同じ class="test" を付けていました。これは正しい書き方です。
IDで同じことをして id="test" を2つに付けると、決まりを破ったことになります。画面には出てしまうこともありますが、やってはいけない書き方です。
「同じ見た目にしたいものが複数ある」なら、迷わずクラスを使ってください。
使い分け
迷ったらクラスを使ってください。実務でも、見た目を整える目的ならほとんどクラスです。
IDは「ページ内に1つしかないもの」に使います。ページ内リンクの飛び先（#top など）にも使われます。

要素型セレクタ

タグの名前をそのまま書くと、そのタグ全部が対象になります。名前を付けなくても狙えます。

li と書く（li だけ） li { background: 黄色; }
  • 1つ目
  • 2つ目
  • 3つ目
* と書く（ul も含めて全部） * { background: 黄色; }
  • 1つ目
  • 2つ目
  • 3つ目
注意
* はページ中のすべての要素に効きます。* の見本では、箱だけでなくそれを囲んでいる ul まで色が変わっています。
影響範囲が広すぎるので、見た目を作る目的で使うことはまずありません。使うのは、余白のリセットなどページ全体に同じ設定をかけたいときだけです。

4. 疑似クラスと疑似要素

名前が似ていますが、別のものです。先に違いを押さえてください。

書き方 やること
疑似クラス コロン1つ　:hover すでにある要素を条件で選ぶ
疑似要素 コロン2つ　::before 要素の前後に中身を足す

疑似クラス ― 条件で選ぶ

「マウスが乗っているとき」「2番目のとき」のように、状態や順番を条件にして選びます。

:hover（マウスを乗せて試せます） li:hover { background: 黄色; }
  • ここにマウスを乗せてください
  • ここでもいいです
  • 乗せている間だけ色が変わります
:first-child（最初の1つ） li:first-child { background: 黄色; }
  • 1つ目
  • 2つ目
  • 3つ目
:nth-child(2)（2番目） li:nth-child(2) { background: 黄色; }
  • 1つ目
  • 2つ目
  • 3つ目
:nth-child(odd)（奇数番目） li:nth-child(odd) { background: 黄色; }
  • 1つ目
  • 2つ目
  • 3つ目
  • 4つ目
odd と even
odd は奇数、even は偶数という意味の英単語です。
:nth-child(even) と書けば、2番目・4番目・6番目…が選ばれます。表の行を1行おきに色分けする、いわゆる縞模様はこれで作ります。
理解ポイント
:nth-child(2) の 2 は「2番目」です。数え方は1からで、0からではありません。
数字のかわりに odd や even と書くこともできる、と覚えておけば十分です。
ほかの疑似クラス
種類はほかにもあります。たとえば :link はまだ訪問していないリンクを指します。
ただ、実務でよく使うのは :hover と :nth-child() です。まずはこの2つを押さえておけば十分です。

疑似要素 ― 前後に中身を足す

::before と ::after は、HTMLに書いていない中身を、CSSだけで足します。何を足すかは content で決めます。

::before（前に足す） li::before { content: "★ "; }
  • 1つ目
  • 2つ目
::after（後ろに足す） li::after { content: " ← ここ"; }
  • 1つ目
  • 2つ目
注意
足した「★」や「← ここ」は、HTMLのどこにも書かれていません。CSSだけで表示されています。
画面には出ますが、文章としては存在しない扱いです。読み上げソフトで読まれないこともあるので、意味のある文章を content で入れるのは避けてください。飾りに使うものです。

もうひとつ、::first-letter は最初の1文字だけを狙います。

指定なし /* 何も書かない */

むかしむかし、あるところに。

::first-letter p::first-letter { font-size: 26px; color: オレンジ; }

むかしむかし、あるところに。

補足
::first-letter は、雑誌の記事などでよく見る「最初の一文字だけ大きくする」飾りを作るときに使います。
なお、:before のようにコロン1つで書かれた古いコードも動きます。いまはコロン2つが正式ですが、既存のサイトでは1つのものをよく見かけます。

5. 属性セレクタと結合子

属性セレクタ ― 属性を条件にする

その前に ― 属性とは
タグの中に、タグ名のうしろへ書き足す情報のことを属性といいます。
<a href="/about"> の href="/about" の部分です。#1で出てきた href がまさにこれにあたります。
じつは <div class="box"> の class="box" も属性です。#5でクラス名を付けたとき、知らないうちに属性を書いていたことになります。

この属性を条件にして、要素を狙うことができます。書き方は 角かっこです。

HTML <a href="/about">会社概要</a> <a href="https://…" target="_blank">外部サイト</a>
  • 会社概要
  • 外部サイト
CSS /* target="_blank" のリンクだけ */ a[target="_blank"]::after { content: " ↗"; }
「会社概要」には何も付かず、
「外部サイト」にだけ「↗」が付きます。
HTMLには書いていない記号です。
よく使う場面
target="_blank" は「別のタブで開く」という指定です。外部サイトへのリンクにだけ印を付けるのは、実務でよくある使い方です。
ほかにも input[type="text"] のように、同じタグでも種類で分けたいときに役立ちます。

結合子 ― 位置関係で狙う

要素どうしの位置関係を条件にする書き方です。3つあります。

記号 呼び方 選ばれるもの
> 子結合子 直下の子だけ（孫は選ばれない）
+ 隣接結合子 すぐ次の1つだけ
~ 間接結合子 後ろに続くもの全部

> ― 直下の子だけ

入れ子が深くなっても、すぐ下の階層だけに効きます。

.wrap > .item .wrap > .item { background: 黄色; }
直下の子
中に入っている（孫）
直下の子
.wrap .item（記号なし） .wrap .item { background: 黄色; }
直下の子
中に入っている（孫）
直下の子
理解ポイント
記号なしでスペースだけ空けて書くと、何階層下でも全部が対象になります。.wrap .item の見本では、いちばん奥の「孫」まで色が変わっています。
> を入れるとすぐ下の階層だけに絞られます。.wrap > .item の見本では、孫が選ばれていません。
2つの見本で違うのは記号1つだけです。

+ と ~ ― 後ろの兄弟を狙う

青い箱を基準にして、その後ろにあるものを狙います。

+（すぐ次の1つ） .mark + .item { background: 黄色; }
前にあるもの
ここが基準
すぐ次
そのまた次
~（後ろに続く全部） .mark ~ .item { background: 黄色; }
前にあるもの
ここが基準
すぐ次
そのまた次
補足
どちらも後ろ側だけが対象です。基準より前にあるものは選ばれません。どちらの見本でも、いちばん上の「前にあるもの」は色が変わっていません。
違いは、+ が1つだけ、~ が全部という点です。
