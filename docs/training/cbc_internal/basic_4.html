1. なぜエクセルをやるのか

Webの勉強をしているのに、なぜ表計算ソフトなのか。理由はプログラミングの考え方を、いちばん早く体験できるからです。

プログラムで「合計を出して表示」する場合 1. データベースに接続する 2. SQLを書いて取り出す 3. 計算する 4. HTMLに埋め込んで表示する 5. ブラウザで開いて確認する → 結果を見るまでの道のりが長い
エクセルで「合計を出して表示」する場合 1. セルに式を書く → その場で答えが出る

「値を受け取って、条件で分けて、計算して、返す」。これはエクセルの関数も、JavaScriptの関数もまったく同じ構造です。
違うのは書き方だけ。エクセルなら1秒で結果が見えるので、考え方の練習に向いています。

Excel がなければ Googleスプレッドシート（無料）や Mac の Numbers でも進められます。
ただし一部の関数は動きが違うことがあります。うまくいかないときは、その関数名で検索してください。

練習用のファイル

2. 数式の基本

式はすべて = から始めます。これが「ここから先は計算です」という合図になります。

手順 やること
1 答えを出したいセルをクリックする
2 = を打つ
3 計算に使いたいセルをクリックする（セル番号が自動で入る）
4 + を打って、次のセルをクリックする
5 Enter で確定する
セル番号は手で打たない
クリックで入れるのが基本です。手で打つと打ち間違いに気づけません。クリックなら、いま何を選んでいるかが色で分かります。
実際にどう見えるかは、3章の画面で動かしています。

四則計算の記号

やりたいこと 記号 例
足す + =D4+D5
引く - =D4-D5
掛ける * =D4*D5
割る / =D4/D5
掛け算は × ではない
掛ける記号は *（アスタリスク）、割る記号は /（スラッシュ）です。
これはエクセルだけでなく、JavaScript でも PHP でも同じです。プログラムの世界で共通の書き方だと思ってください。

オートフィルコピー

同じ形の式を、隣のセルにも入れたい。1つずつ打つ必要はありません。

手順 やること
1 式を入れたセルを選ぶ
2 セルの右下の角にカーソルを合わせる（＋の形に変わる）
3 そのままドラッグする
便利なのは、参照が自動でズレること
=D4+D5 を右にコピーすると、自動で =E4+E5 になります。列が1つ動いたぶん、参照も1つ動く。
この「相対的にズレる」性質を相対参照と呼びます。ズレてほしくない場合の書き方は 中級#5 で扱います。

ところで、4月から3月までの合計を出すとき =D3+E3+F3+G3+H3+I3+J3+K3+L3+M3+N3+O3 と書くことになります。12個。
不便だと思いませんか。こういうときのために SUM というものがあります。詳しくは「エクセル SUM 使い方」で検索してみてください。

調べて使えるようになる、というのは実務でずっと必要になる力です。知らない関数に出会ったら、まず検索する。この習慣を今のうちから作っておいてください。

3. IF ― 条件で切り分ける

売上表で利益率を出します。式は「利益 ÷ 売上」です。ところが、ここで問題が起きます。

IF fx =IF(D4=0,"",D6/D4)
A B C D E F
1
24月5月6月
3株式会社サンプル目標売上2,000,0001,300,0001,200,000
4売上高707,625261,000879,000
5仕入れ127,22441,14725,030
6粗利益580,401219,853853,970
7利益率=IF(D4=0,"",D6/D4)82.0%
8目標達成率
9エグザンプル株式会社目標売上3,485,0173,376,4009,353,777
答えを出したいセル（D7）をクリックする = を打ち、使うセルをクリックしていく 式ができた。参照したセルに色が付いている Enter で確定すると、結果が出る

左上が名前ボックス、その右が ×（取り消し）、✓（確定）、fx（関数の挿入）。右に伸びているのが数式バーです。

式を打っていくと、参照したセルに色が付いていきます。D4 を打てば売上高のセルが青に、D6 を打てば粗利益のセルがオレンジに。式の中の色と、表の中の色が対応しています。
いま自分がどのセルを指しているかを、目で確かめながら書けるということです。手でセル番号を打つのではなくクリックで入れるのは、これを見るためでもあります。

まだ売上のない月
売上が 0 の月を計算すると、#DIV/0! というエラーが出ます。
0で割ることはできないからです（算数でも「10 ÷ 0」は答えが出ません）。

IF の形

数式バー
IF の書き方
1 2 3 4 5
=IF(
  条件,
  「条件に合ったとき」の答え,
  「合わなかったとき」の答え
)

これを利益率に当てはめると、こうなります。

数式バー
利益率
1 2 3 4 5
=IF(
  D4=0,
  "",
  D6/D4
)
部分 意味
D4=0 もし売上（D4）が 0 なら
"" 何も表示しない（空っぽ）
D6/D4 そうでなければ、利益 ÷ 売上を計算する
"" は「空っぽの文字」
ダブルクォート2つ "" は「文字が1つもない状態」を表します。0 でもスペースでもなく、空です。
この書き方も、JavaScript や PHP と共通です。

実際に試してみる

売上の数字を 0 に変えてみてください。左と右で結果が変わります。

IF なし =D6/D4 -
IF あり =IF(D4=0, "", D6/D4) -
エラーは「防ぐ」もの
エラーが出てから直すのではなく、起きうる条件をあらかじめ考えて、逃げ道を用意しておく。
この考え方はプログラムでもまったく同じです。「値が空だったら」「0だったら」を先に潰すのが、動くものを作る人の習慣です。

4. エラー表示の読み方

エクセルのエラーは種類ごとに名前が付いています。読めれば原因がすぐ分かります。

表示 意味 よくある原因
#DIV/0! 0で割っている まだ数字が入っていないセルで割った
#VALUE! データの種類が違う 文字が入っているセルを計算に使った
#NAME? 名前が間違っている 関数名のスペルミス
#NUM! 数値が大きすぎる／小さすぎる 計算結果が扱える範囲を超えた
#REF! 参照できない 式が参照していた行や列を削除した
#N/A 値が見つからない 検索した結果、該当がなかった
#NULL! 範囲の指定ミス 範囲の書き方が間違っている
エラーは敵ではない
エラーは「ここがおかしい」と教えてくれているだけです。無視して消すのではなく、何を言っているのかを読む。
この先、ブラウザでプログラムを書くようになっても同じです（中級#7）。読む習慣がある人だけが、早く直せます。

IS系関数で先に防ぐ

「中身がどうなっているか」を調べる関数があります。IF と組み合わせて使います。

関数 調べること
ISBLANK() 空っぽかどうか
ISERROR() エラーかどうか
ISNUMBER() 数値かどうか
ISTEXT() 文字かどうか
空っぽなら「-」を出す =IF( ISBLANK(D1), "-", D2/D1 )
何か入っていれば計算する =IF( D1>"", D2/D1, "" )
D1>"" の読み方
「空っぽより大きい」＝「何か入っている」という意味です。少し変わった書き方ですが、実務ではよく見かけます。
ISBLANK() のほうが読んで分かりやすいので、自分で書くならこちらをおすすめします。

5. 文字の中に数字を埋め込む ― TEXT

報告書に「今年の売上高は 1,250,000 円でした。」と書きたい。数字を手で打つと、あとで数字が変わったときに直し忘れます。

これがヒューマンエラー対策
「同じ情報を2箇所に書かない」。表の数字と文章の数字が別々にあると、必ずどこかで食い違います。
式でつないでおけば、表を直せば文章も自動で直ります。初級#3 でCSSの重複を避けたのと、まったく同じ考え方です。

書き方

数式バー
TEXT の書き方
1
="何か文字列" & TEXT(対象のセル, "表示形式") & "何か文字列"
部分 意味
& 文字と文字をつなぐ記号
"…" そのまま表示したい文字（クォートで囲む）
TEXT(セル, 形式) 数値を指定した見た目の文字に変える

表示形式の記号

記号 意味
# 数字1桁。余分な 0 は表示しない
0 数字1桁。桁が足りなければ 0 を表示する
? 小数の桁数を揃えたいときに使う
, 3桁ごとのカンマ
% 100倍して % を付ける

実際に試してみる

数字を打ち替えると、下の文章がそのまま変わります。

="今年の売上高は" & TEXT(P17,"#,0") & "円でした。" -
="今年の目標達成率は" & TEXT(P21,"#.#0%") & "です。" -
TEXT を通すと「文字」になる
TEXT() の結果は数値ではなく文字です。見た目は数字でも、それ以上の計算には使えません。
計算に使いたい値と、表示のための値は別に持つのが安全です。

6. 切り捨て・切り上げ ― FLOOR / CEILING

来年の売上目標を立てるとき、1,373,482円 という数字をそのまま目標にはしません。キリのいい数字に丸めます。

関数 やること 書き方
FLOOR 基準値の倍数に切り捨てる =FLOOR(数値, 基準値)
CEILING 基準値の倍数に切り上げる =CEILING(数値, 基準値)

floor は「床」、ceiling は「天井」。数直線を思い浮かべて、下（床）に落とすのが FLOOR、上（天井）に持ち上げるのが CEILING です。
この2つの名前は、JavaScript にも Math.floor() / Math.ceil() として同じ意味で存在します。

基準値がポイント

100単位で切り捨て =FLOOR(A1, 100) 2,560 → 2,500
15分単位で切り上げ =CEILING(A1, "0:15") 56:37 → 56:45

勤怠管理で「15分単位で切り上げる」のような処理は、この CEILING そのものです。
基準値を "0:15" と書けば15分単位、"0:30" なら30分単位になります。

実際に試してみる

売上に数字を入れると、3種類の目標額が同時に出ます。10万円単位で丸めています。

式 結果 意味
1 =FLOOR(D17, 100000) - 10万円単位で切り捨て
2 =CEILING(D17, 100000) - 10万円単位で切り上げ
3 =CEILING(D17*110%, 100000) - 110%にしてから切り上げ（来年の目標）

3行目は、D17*110% で1割増しにしてから、10万円単位に切り上げています。
「今年より1割多い、キリのいい数字」を1行で出しているわけです。これが関数を組み合わせるということです。

配布したエクセルに関して
配布ファイルの下のほうに 目標売上A（切り捨て） 目標売上B（切り上げ） 目標売上C（10%UP+切り上げ） という3行があります。
これはA社・B社という意味ではなく、丸め方の違いです。同じ売上から、計算方法を変えると目標値がどう変わるかを並べて比べるための3行で、上の表の1〜3行目とそのまま対応しています。
会社ごとの区分は表の左側（株式会社サンプル / エグザンプル株式会社 / 全体）で分かれています。
このページで身についたこと
条件で分ける（IF）／エラーを先に防ぐ／値を組み立てて表示する（TEXT）／数を整える（FLOOR・CEILING）。
名前と書き方が違うだけで、やっていることはプログラムとまったく同じです。
