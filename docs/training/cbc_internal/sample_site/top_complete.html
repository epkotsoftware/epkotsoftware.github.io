つくることが、いちばんの近道

SAMPLE SITE は、Web制作をこれから学ぶ人のための練習用サイトです。 枠を組み立て、色や画像を入れ、1ページを完成させるまでの流れを、 実際に手を動かしながら体験できます。 読むだけでは身につかないことも、作ってみれば自然と分かるようになります。

Lesson

HTML と CSS の基礎から、実際のページを組み立てるところまで。
ひとつずつ手を動かして確かめながら進むので、
はじめての人でも迷わず最後までたどり着けます。

  • HTML & CSS

    Webページの構造と装飾。枠組みからレイアウトまでの基礎を学びます。

  • JavaScript

    動きのあるページ作り。DOM操作やイベントの基本を身につけます。

  • PHP

    サーバーサイドの入門。フォーム処理やDB連携の第一歩を学びます。
