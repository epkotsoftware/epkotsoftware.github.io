1. 枠のことを「要素」と呼ぶ

ここまで「枠」と呼んでいたものを、これ以降は要素と呼びます。実務の現場でも、調べもので出てくる解説サイトでも、この呼び方が使われます。

要素とは、HTMLのタグで作られたもの全部を指します。<div> のような箱も、<p> の中の文章も、<img> の画像も、すべて要素です。

書いたもの 呼び方
<div>〜</div> div要素
<p>〜</p> p要素
<img> img要素

このように、タグ名 + 要素という呼び方をします。「divタグ」と言うこともありますが、正確にはタグは目印、要素はタグで作られたもの全体を指します。

理解ポイント
タグで囲んで作ったものは、見た目が箱でも文字でも画像でも、まとめて「要素」と呼びます。

親要素と子要素

要素の中に別の要素を入れたとき、外側を親要素、内側を子要素と呼びます。この章から先は、この2つの言葉が何度も出てきます。

<div>中の要素から見れば「親要素」
<div>外の要素から見れば「子要素」

2. flexで横に並べる

その前に ― クラスで指定する

ここまでの教材では、div { ... } のようにタグ名で指定してきました。ただしこの書き方には問題があります。ページ中のすべての div に効いてしまうのです。

補足

理解ポイント
HTMLは1文字も変えていません。親要素にCSSを1行足しただけで、縦並びが横並びになりました。
flexは「子要素の並べ方を、親がまとめて決める」仕組みです。

用語 ― flexコンテナとflexアイテム

display: flex; を書いた親要素を flexコンテナ、その中に並ぶ子要素を flexアイテム と呼びます。調べものをするときに必ず出てくる言葉です。

補足

孫も並べたければ、子のほうにも display: flex; を書きます。

横並びにしたいときは、「並べたい要素たちを囲んでいる親は誰か」を先に確認してください。

3. 親に指定するプロパティ

ここから紹介するプロパティは、すべて親要素に書きます。子の並び方を、親がまとめて決めるためのものです。

6つありますが、いま全部覚えなくて大丈夫です。「こういう指定ができる」と知っておいて、必要になったら見に戻ってくれば十分です。

プロパティ 決めること
flex-direction 子要素が並ぶ向き
flex-wrap 収まらないときに折り返すか
flex-flow 上の2つをまとめて書く
justify-content 並んでいる方向の位置
align-items 並びと直角の方向の位置
align-content 折り返して複数行になったときの、行全体の位置
見方
以降の見本は画像ではなく、実際にそのプロパティを効かせて表示しています。点線の枠が display: flex; を書いた親要素、青い箱が子要素です。
色・枠線・余白は、どこが親でどこが子か見分けるために付けているだけです。flexの動きとは関係ないので、コードには載せていません。

4. 子に指定するプロパティ

次は子要素に書くプロパティです。3章が「全体をどう並べるか」だったのに対して、こちらは「並んだうちの、この要素だけどうするか」を決めます。

こちらも6つありますが、実際によく使うのは flex と flex-grow のあたりです。まずは雰囲気をつかんでください。

flex-basis 伸び縮みする前の基準の大きさ auto
flex 上の3つをまとめて書く 0 1 auto
align-self その要素だけの縦方向の位置 auto
見方
以降の見本では、プロパティを指定した子要素だけオレンジ色にしてあります。青は何も指定していない子要素です。
この色分けは説明のためのもので、コードには載せていません。載せているのは、その見本で実際に効いているflexの指定だけです。

セレクタの読み方
:first-child は「最初の子」、:nth-child(2) は「2番目の子」を指します。クラス名だけを書けば全部に効き、これらを付けると特定の1つだけに効きます。上の2つ目と3つ目は、書いているプロパティは同じでセレクタだけが違います。
なぜ見本ごとに幅が変わるのか
余白を分け合うのは、flex-grow を1以上にした要素だけです。既定値の 0 は「余白をもらわない」という意味なので、指定していない要素は文字ぶんの幅のまま残ります。
「1番目だけ」の見本は、余白を受け取る要素が1個しかないので、その1個が全部を独占します。だからあれほど大きく広がります。
「全部に1」の見本は3個で分け合うので、1個あたりの取り分は3分の1になります。同じ flex-grow: 1 でも、他にいくつ指定されているかで結果が変わります。
よくある誤解
flex-grow: 2 にしても、その要素の幅が2倍になるわけではありません。2倍になるのは余った空間の取り分だけです。
上の見本でも、2番目は1番目のちょうど2倍にはなっていません。もとから持っている箱の幅（文字と内側の余白の分）に、取り分が足されるからです。

中身の文字数に影響されないようにする

ここまでの見本は、どれも中身が「1」「2」「3」で同じ幅でした。中身の文字数が違うと、flex-grow だけでは幅が揃いません。もともとの中身の幅が残ったまま、余りを分け合うからです。

flex-basis を 0 にすると、もともとの中身の幅が計算から外れます。文字数が違っても、同じ幅で並ぶようになります。

flex-grow、flex-shrink、flex-basis は flex で1行にまとめられます。実務ではこちらのほうがよく使われます。

5. 組み合わせてレイアウトを作る

ここまでのプロパティを組み合わせると、実際のWebサイトでよく見る形が作れます。どれも数行のCSSで済みます。

ここが一番おもしろいところです。3章と4章で見たものが、どう組み合わさって画面になるのかを見ていきましょう。

上下左右の中央に置く

justify-content と align-items の両方を center にします。flexが登場する前は面倒だった中央寄せが、2行で片付きます。 

.container {
  /* ここがflexの指定 */
  display: flex;
  justify-content: center;  /* 左右の中央 */
  align-items: center;      /* 上下の中央 */

  /* ここから下は見た目を整えるだけ */
  height: 150px;
  background-color: #f1f5f9;
  border: 2px dashed #94a3b8;
}

.item {
  padding: 12px 16px;
  background-color: #bfdbfe;

ひとつだけ右に寄せる

「左に2つ、右に1つ」のように分けたいときは、右に送りたい要素へ margin-left: auto; を付けます。余った空間をすべてその左側の余白が吸い取るので、要素が右端まで押し出されます。 

.container {
  display: flex;
  gap: 8px;
}

/* 右端へ送りたい要素にだけ書く */
.login {
  margin-left: auto;
}

justify-content: space-between; でも似たことができますが、あちらは全体の配り方を変えるので、要素が3つ以上あると間隔が均等に開きます。「この要素だけ右端へ」を狙うなら margin-left: auto; のほうが確実です。

理解ポイント
flexは1階層ぶんしか効きません。だから入れ子が2段あるヘッダーでは、flexも2箇所に書くことになります。
.header の flex → ロゴとメニューを左右に分ける。.nav の flex → メニューの項目を横に並べる。それぞれ別の仕事をしています。
補足
「flexの中にflex」は特殊な書き方ではなく、実務ではごく普通です。ページ全体をflexで組むと、入れ子の数だけflexが出てきます。

サイドバーとメインに分ける

サイドバーは幅を固定し、メインは残り全部を使う形です。サイドバーに flex: 0 0 110px;（伸びず縮まず110px）、メインに flex: 1;（余りを全部もらう）を指定します。 

.container {
  display: flex;
  gap: 8px;
  height: 150px;
}

.side {
  flex: 0 0 110px;           /* 幅を110pxで固定 */
  background-color: #fde68a; /* 見た目だけ */
}

.main {
  flex: 1;                   /* 残りを全部使う */
  background-color: #bfdbfe; /* 見た目だけ */
}

理解ポイント
幅は width でも指定できますが、flex の3つ目の値（flex-basis）で書くと、伸びる・縮む・基準の幅を1行にまとめられます。どちらの書き方でも、メイン側が自動で伸び縮みして隙間やはみ出しは出ません。

カードを均等に並べる

すべての子要素に flex: 1; を付けると、幅が均等になります。中身の文字数が違っても揃います。 

.container {
  display: flex;
  gap: 8px;
}

.card {
  flex: 1;                   /* ここだけがflexの指定 */

  /* ここから下は見た目を整えるだけ */
  padding: 12px;
  background-color: #bfdbfe;
  border-radius: 5px;
  text-align: center;
}

補足
文字数が大きく違っても幅が揃うのは、flex: 1 が flex-basis: 0% を含んでいるからです。「中身の大きさを無視して、余白を等分する」という意味になります。中身の大きさを基準にしたいときは flex: 1 1 auto; と書きます。

まとめ

やりたいこと 書くもの
横に並べる 親に display: flex;
上下左右の中央に置く 親に justify-content: center; と align-items: center;
両端に分ける 親に justify-content: space-between;
ひとつだけ右端へ その子に margin-left: auto;
幅を固定する その子に flex: 0 0 幅;
残りを全部使う その子に flex: 1;
均等に並べる すべての子に flex: 1;
理解ポイント
プロパティは12個ありますが、実務で使う頻度はかたよっています。まずは display: flex、justify-content、align-items、flex: 1 の4つを確実に使えるようにしてください。これだけで大半のレイアウトが組めます。
残りは覚えなくて大丈夫です。「そういえばそんな指定があったな」と思い出して、ここに戻って調べられれば、それで十分に仕事になります。
