1. 変数 ― 値に名前を付ける

値に名前を付けて、取っておく仕組みです。付けた名前を書けば、いつでもその値を呼び出せます。

main.js — Visual Studio Code
main.js
1 2 3
const userName = '田中';

// これ以降、userName と書けば '田中' のこと
部分 意味
const これから変数を作る、という合図
userName 付ける名前（自分で決める）
= 入れるという意味（等しい、ではない）
'田中' 入れる値
= は「等しい」ではない
算数の = は「左と右が等しい」という意味ですが、プログラムの = は「右の値を、左の名前に入れる」という意味です。
向きがあります。右から左へ入れる、と覚えてください。

const と let

変数を作る書き方は2つあります。違いはあとから値を入れ替えられるかどうかだけです。

書き方 あとから入れ替え 使いどころ
const できない 基本はこちら
let できる 入れ替える必要があるときだけ
✕ const は入れ替えられない const count = 1; count = 2; // エラーになる
○ let なら入れ替えられる let count = 1; count = 2; // これはOK
理解ポイント
迷ったら const を使ってください。そして「入れ替えないと書けない」となったときだけ let に変えます。
なぜかというと、const にしておくと「この値は途中で変わらない」と保証されるからです。後からコードを読む人（未来の自分を含む）が、値の変化を追いかけずに済みます。
var という書き方
古いコードでは var という書き方を見かけます。これは const と let が使えるようになる前の書き方です。
いま新しく書くなら使いませんが、既存のサイトを直すときには出てきます。「昔の let のようなもの」と考えておけば読めます。

名前の付け方

まず守らないとエラーになる決まりです。

決まり 例
使えるのは英数字と _ $ ✕ user-name（ハイフンは使えない）
数字から始められない ✕ 1stName
大文字と小文字は別物 name と Name は違う変数

次にエラーにはならないけれど、揃えたほうがいい書き方です。

2語以上をつなぐとき、書き方にはいくつか流儀があります。それぞれに名前が付いています。

呼び方 つなぎ方 例 主に使われる場所
キャメルケース 2語目から頭を大文字 userName JavaScript の変数・関数
パスカルケース 1語目から頭を大文字 UserName クラス名
スネークケース _ でつなぐ user_name PHP の変数、データベースのカラム名
ケバブケース - でつなぐ user-name CSS のクラス名、HTML の id
名前の由来
キャメルはラクダ。userName の出っぱりがこぶに見えることから。
パスカルは Pascal というプログラミング言語から。アッパーキャメルケースとも呼ばれます。
スネークは蛇。_ が地を這う姿に見えることから。
ケバブは串焼き。- が串に刺さった具に見えることから。チェーンケースとも呼ばれます。
ケバブケースは、もう書いています
CSS のプロパティ名を思い出してください。font-size、text-align、background-color。すべてケバブケースです。
コーダー初級#2 から書いてきたものに、名前が付いているだけです。
スネークケースは、このあと出てきます
PHP の変数やデータベースのカラム名で使われます。user_name、total_price のような書き方です。
フロントエンドエンジニア編でデータベースを扱うときに出てきます。いまは「そういう書き方もある」と知っておけば十分です。
JavaScript ではキャメルケース
user_name と書いても動きはします。ただし JavaScript ではキャメルケースが標準です。こちらに揃えてください。
ケバブケースは使えません。上の表のとおり - は引き算と区別できないためです。
user-name と書くと、user から name を引くという意味になってしまいます。
なぜ揃えるのか
1人で書くなら、どれでも動きます。揃える理由は、読む人のためです。
名前の形が揃っていれば、userName を見た瞬間に「これは変数だ」と分かります。形そのものが情報になるということです。
現場ではそのプロジェクトの書き方に合わせます。自分の好みより、周りとの統一が優先されます。
名前は中身が分かるものに
a や data のような名前は、あとから読むと何が入っているか分かりません。userName、totalPrice のように、中身が分かる名前を付けてください。
名前を考える時間は無駄ではありません。読み返す時間のほうが、書く時間よりずっと長いからです。

2. 関数 ― 処理に名前を付ける

変数が「値に名前を付ける」ものなら、関数は「処理のまとまりに名前を付ける」ものです。

名前を付けておくと、何度でも呼び出せます。同じ処理を何回も書かずに済みます。

作り方と呼び出し方

main.js — Visual Studio Code
main.js
1 2 3 4 5 6 7
// 作る（この時点では、まだ動かない）
function sayHello() {
  console.log('こんにちは');
}

// 呼び出す（ここで初めて動く）
sayHello();
理解ポイント
作っただけでは動きません。呼び出して初めて中身が実行されます。
マークアップ中級#6 で $('.btn').on('click', function() { … }) と書きましたよね。あれは「クリックされたときに呼び出してください」とjQueryに預けている状態です。だから書いた瞬間には動かなかったのです。

材料を渡す ― 引数

関数に材料を渡せます。渡す値のことを 引数（ひきすう） と呼びます。

材料なし function sayHello() { console.log('こんにちは'); } sayHello(); // → こんにちは
材料あり（引数） function sayHello(name) { console.log(`${name}さん、こんにちは`); } sayHello('田中'); // → 田中さん、こんにちは
引数は入れ物の名前
function sayHello(name) の name は、渡された値を受け取る入れ物です。関数の中でだけ使える変数、と考えてください。
呼び出すときに sayHello('田中') と書くと、name の中身が '田中' になります。

結果を返す ― 戻り値

関数は計算した結果を返せます。返す値のことを 戻り値（もどりち） と呼び、return で指定します。

main.js — Visual Studio Code
main.js
1 2 3 4 5 6 7
// 税込価格を計算して返す
function withTax(price) {
  return Math.floor(price * 1.1);
}

const total = withTax(1000);
// total の中身は 1100
理解ポイント
return があると、関数を呼び出した場所が、その値に置き換わります。
withTax(1000) と書いた場所が 1100 になる、というイメージです。だから const total = withTax(1000); で total に 1100 が入ります。
Math.floor とは
小数点以下を切り捨てる命令です。1000 * 1.1 は 1100.0000000000002 のような値になることがあるため、切り捨てて整数にしています。
いまは「そういう命令がある」とだけ知っておけば十分です。

動かしてみる

金額を入れると税込価格を返す関数です。数字を入れてボタンを押してください。

コード // 税込価格を計算する関数 function withTax(price) { return Math.floor(price * 1.1); } $('#tax-btn').on('click', function() { const price = Number($('#price-input').val()); const total = withTax(price); $('#tax-out').text(`税込 ${total} 円`); });
動く見本
ここに結果が出ます
Number() が必要な理由
入力欄から .val() で取り出した値は、数字を入れても「文字」として扱われます。
文字のまま計算すると、'1000' * 1.1 のように意図しない結果になることがあります。Number() で数値に変換してから計算してください。
これは実務でも本当によくハマるところです。

もうひとつの書き方 ― アロー関数

同じ関数を、こう書くこともできます。いまのJavaScriptではこちらもよく使われます。

function で書く function withTax(price) { return Math.floor(price * 1.1); }
アロー関数で書く（同じ意味） const withTax = (price) => { return Math.floor(price * 1.1); };
名前の由来
=> が矢印（arrow）に見えることからアロー関数と呼ばれます。
どちらの書き方でも結果は同じです。既存のコードでは両方出てくるので、読めるようにしておいてください。
jQueryのイベントでは function を使う
ここは重要です。マークアップ中級#6 で使った $(this) は、アロー関数の中では正しく動きません。
アロー関数は this を持たない仕組みになっているためです。jQueryのイベントを書くときは function() { … } を使ってください。
○ function なら $(this) が使える $('.btn').on('click', function() { $(this).addClass('active'); });
✕ アロー関数だと this がずれる $('.btn').on('click', () => { $(this).addClass('active'); // this がボタンを指さない });

いま出てきた3つが、基本の種類です。

種類 呼び方 例
文字 文字列（string） '田中'　'こんにちは'

CSSで位置と見た目を決める

位置合わせはCSSの仕事です。コーダー中級#5 でやった flex と、position: fixed を組み合わせます。

style.css — Visual Studio Code

.overlay {
  /* 画面全体を覆う */
  position: fixed;
  inset: 0;
  background: rgba(15, 23, 42, 0.55);

  /* 中身を上下左右の中央に置く */

  align-items: center;

  opacity: 0;

.overlay.is-open {
  opacity: 1;

}
position: fixed とは
コーダー中級#6 で relative と absolute を扱いました。fixed はその仲間で、画面そのものを基準にする指定です。
ページをスクロールしても位置が変わりません。画面全体を覆いたいモーダルには、これがぴったりです。
inset: 0 とは
top: 0; right: 0; bottom: 0; left: 0; を1行にまとめた書き方です。position: fixed と組み合わせると画面いっぱいに広がります。

役割を分ける
位置・大きさ・見え方はCSS。開くか閉じるかの切り替えだけがjQuery。
昔は要素の幅や高さをJavaScriptで計算して中央に置いていましたが、いまは flex で済みます。CSSでできることはCSSでやると、コードが短くなり、壊れにくくなります。

大きさを測るメソッド

いまは使わずに済みましたが、要素の大きさを測るメソッドもあります。既存のサイトでは、これで位置を計算しているコードをよく見かけます。

メソッド 測る範囲
.width() / .height() 中身だけ（余白と枠線を含まない）
.outerWidth() / .outerHeight() 余白と枠線も含めた外側の大きさ
コード const $box = $('#box'); console.log($box.width()); console.log($box.outerWidth());
動く見本
中身の幅 + 余白16px + 枠線4px

数字が違う理由
同じ箱を測っているのに、数字が変わります。.width() は中身だけ、.outerWidth() はそこに余白（padding）と枠線（border）を足した外側の大きさを返すからです。
「どこまでを大きさと数えるか」が違うだけです。
なお、実際の数値は小数で返ることがあります。上の見本は、見やすいように整数へ丸めて表示しています。
いまは出番が減りました
これらはJavaScriptで位置を計算していた時代のものです。いまは flex や position でCSS側に任せられるので、新しく書くときに使う場面はほとんどありません。
既存のサイトで見かけたときに「大きさを測っているんだな」と読めれば十分です。

動かしてみる

実際に開きます。画面全体が覆われるので、「閉じる」か背景をクリックすると戻ります。

背景クリックで閉じる
上の見本は、暗い背景の部分をクリックしても閉じます。よく使われる作りなので、コードも載せておきます。
e.target は「実際にクリックされた要素」を指します。それが覆う部分そのものだったとき（＝小窓の外側だったとき）だけ閉じる、という書き方です。
$('.overlay').on('click', function(e) { // 小窓の中をクリックしたときは閉じない if (e.target === this) { $(this).removeClass('is-open'); } });

まとめ

覚えること 書き方
値に名前を付ける const 名前 = 値;
あとで入れ替える値 let 名前 = 値;
処理に名前を付ける function 名前() { … }
材料を渡す function 名前(引数) { … }
結果を返す return 値;
中身を確かめる console.log(値);
文字に変数を埋め込む `${変数}です`（バッククォート）
文字を数値にする Number(値)
理解ポイント
ここで出てきた変数・関数・引数・戻り値は、JavaScriptだけのものではありません。PHPでも、他のどの言語でも、同じ考え方が出てきます。
書き方の細かい違いはありますが、「値に名前を付ける」「処理に名前を付けて呼び出す」という構造は共通です。ここを掴んでおくと、次の言語を学ぶときの負担がまったく違います。
