21. 完成したレイアウトを拡張する

前回までで、ヘッダー・メインビジュアル・フッターという基本のレイアウトが完成しました。今回は、この完成したレイアウトを土台にして、実際のWebサイトに近い形へ拡張していきます。

すでにある枠組みを壊さずに、部品を足していくのがこの回のテーマです。追加するのは次の3つです。

3つの拡張目標

  1. ヘッダーにナビゲーションを追加する（メニューのリンクを横並びにする）
  2. コンテンツ内容を増やす（レッスンカードとキャッチコピーを追加する）
  3. フッターにリンク集を追加する（複数カラムのリンクを並べる）

22. 素材画像を準備する

拡張したサイトでは、ロゴやレッスンカードのサムネイルなどの画像を表示します。実際の制作では、画像素材をプロジェクト内の images フォルダにまとめて置きます。
前ページでダウンロードした images.zip には、レッスンカードのサムネイル3枚（HTML & CSS / JavaScript / PHP）も含まれています。まだ配置していない場合は、下のボタンからダウンロードし、展開して出てきた images フォルダを index.html と同じ場所に置きましょう。

images.zip をダウンロード ロゴ・カードのサムネイル画像の素材一式

フォルダ構成

mysite/
├── index.html
├── css/
│   └── style.css
└── images/
    ├── logo_mark.webp   ← ロゴ画像
    ├── top_bg.webp      ← メインビジュアルの背景画像
    ├── card_html.webp   ← レッスンカード（HTML & CSS）
    ├── card_js.webp     ← レッスンカード（JavaScript）
    └── card_php.webp    ← レッスンカード（PHP）
注意
index.html と同じ階層に images フォルダがある場合、HTML からは <img src="images/ファイル名"> と書きます。フォルダ名やファイル名が1文字でも違うと画像は表示されません。

今回はじめて出てくる書き方

完成コードには、次の5つが新しく登場します。いずれも詳しい使い方は今後の研修で扱います。

書き方 意味
list-style: none リストの先頭に標準で付く「●」を消す。ナビ・メニュー・リンク集の <ul> にまとめて指定する
color: inherit
text-decoration: none		 リンクの青い文字＋下線を消し、まわりの文字になじませる（inherit ＝ 親の枠の文字色を受け継ぐ）
:hover 疑似クラス。マウスを乗せたときだけ効く指定
flex: 1 / flex: 3 横並びにした枠の幅を数値の比率で分ける（ここでは 1 : 3）
space-between
space-around		 横並びの配置のしかた。between は両端いっぱいに寄せて間を均等に、around はそれぞれの左右に均等な余白（前ページの center は中央にまとめる）
理解ポイント
今回追加した部品は、どれも「枠を作って（div）、flex で並べる」の繰り返しです。ナビ・カード・フッターと、見た目は違っても仕組みは同じです。これまで学んだ基本の組み合わせだけで、本格的なレイアウトが作れることを確認しましょう。
