1. Web 開発環境を知る

ここからは PHP を使って、サーバー側で動くプログラムを作っていきます。その前に、そのプログラムがどこで動くのか、どんな部品が組み合わさっているのかを押さえておきましょう。

ローカル環境とは

公開されている Web サイトは、インターネット上のサーバーというコンピューターの中で動いています。しかし開発中のプログラムを、いきなり公開サーバーに置いて試すわけにはいきません。

そこで、自分のパソコンの中に、公開サーバーとよく似た環境を作ります。これをローカル環境と呼びます。自分のパソコンの中だけで完結するので、何度失敗してもよく、誰にも見られません。

補足
本番環境に似せて作ったテスト用の環境を ステージング環境（staging、略して stg）と呼ぶこともあります。実務では「本番」「ステージング」「ローカル」と段階を分けて開発します。

Web サイトを動かす 4 つの部品

Web サーバーは 1 つのソフトでできているわけではなく、役割の違う部品が組み合わさって動いています。代表的な構成は次の 4 つです。

部品 役割 代表的なソフト
OS 土台となる基本ソフト Linux
Web サーバー ブラウザからの要求を受け取り、結果を返す Apache、nginx
データベース データを保存し、必要なときに取り出す MySQL、PostgreSQL、MariaDB
スクリプト言語 受け取った要求を処理し、表示する内容を組み立てる PHP

この 4 つの頭文字をとって LAMP 環境（ランプ）と呼びます。Linux・Apache・MySQL・PHP の組み合わせという意味です。

研修で使う環境

本来この LAMP 環境は、自分のパソコンに 1 つずつインストールして設定する必要があり、手間がかかります。研修では Docker という仕組みを使って、必要な部品がそろった状態の環境をあらかじめ用意しています。

用意されているのは次の 3 つです。それぞれ役割が違い、ブラウザで開くときのポート番号も異なります。

役割 中身 ブラウザで開く URL
Web サーバー Apache ＋ PHP http://localhost:8001/
データベース MySQL （ブラウザからは直接開かない）
データベース管理ツール phpMyAdmin http://localhost:8888/
理解ポイント
phpMyAdmin は、データベースの中身をブラウザから見たり編集したりするための道具です。データベース本体（MySQL）とは別のソフトで、後の章でテーブルを作るときに使います。

ファイルを置く場所

書いた PHP ファイルは、自分のユーザーフォルダの 03_advanced/htdocs/ に置きます。このフォルダは Web サーバーの中と同期しているので、保存すればすぐブラウザで確認できます。

自分のパソコン ブラウザで開く URL
03_advanced/htdocs/index.php http://localhost:8001/index.php
03_advanced/htdocs/test.php http://localhost:8001/test.php
注意
ポート番号（8001 の部分）は、複数の環境を同時に動かしたときにぶつからないよう区別するための番号です。
