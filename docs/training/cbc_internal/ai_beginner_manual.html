無料と有料、どう違う？

無料プラン

無料プランでできること

  • 分からないことを聞く
  • 文章を作ってもらう・直してもらう
    例：メール、A4数枚程度の案内文、議事録から作る報告書
  • コードを作ってもらう・直してもらう
    例：簡単なWebページ、電卓、ToDoリストのコード一式
  • Codexでファイルを直接編集する
    例：ToDoリストに検索欄を付け、動くか確認してもらう
  • ChatGPTで画像を作る
    例：カフェの紹介ページに使うコーヒーのイラスト

長いものや複雑なものは、分けて作り、修正を重ねます。
チャットで受け取ったコードは、自分でVS Codeなどにコピーして使います。

有料プラン

無料プランでできることに加えて

  • Claude Pro：Coworkが使える
    指定フォルダーの議事録3件を読み、決まったこと・担当者・期限をまとめたWordファイルの作成まで頼める
  • Claude Pro：Claude Codeが使える
    Claudeの開発ツールで、ToDoリストのファイルに検索欄を追加し、動くか確認するところまで頼める
  • ChatGPT Plus：Codexの作業中に画像生成も使える
    カフェの紹介ページを編集しながら、コーヒーのイラスト作成とページへの配置もまとめて頼める

AIに作業を任せる準備をする。

データの扱い、作業フォルダ、権限、モデルを確認してから始めます。
準備ができたら、次の練習例で割り勘計算機を作ります。

01　個人アカウントのデータ設定

モデル改善への利用をオフにする。

無料・有料どちらも、最初に確認します。Windows・Macともに、ブラウザから設定できます。

ChatGPT・Codex

  1. ChatGPTを開き、プロフィールアイコン → 「設定」 → 「データコントロール」。
  2. 「すべての人のためにモデルを改善する」をオフにします。

同じアカウントで使うCodexの会話にも反映されます。設定の手順・Codexへの適用

Claude・Claude Code

  1. Claudeで自分の名前 → 「設定」 → 「プライバシー」。設定画面を開く
  2. 「AIモデルの改善を支援する」をオフにします。

同じ個人アカウントで使うClaude Codeにも適用されます。公式の手順

Codexの「環境全体」の共有も確認する

Codexの設定で、環境全体を学習に使う共有設定が表示される場合は、オフにします。これはChatGPTの会話の設定とは別です。公式の説明

オフにしても、情報の送信や保存がなくなるわけではありません。
個人情報や秘密情報は、引き続き入力しません。

02　作業フォルダを用意する

空の「AI練習」フォルダを作る。

Windows

デスクトップの何もない所を右クリック。
「新規作成」→「フォルダー」を選び、名前を「AI練習」にします。

Mac

デスクトップの何もない所を右クリック（トラックパッドは2本指でクリック）。
「新規フォルダ」を選び、名前を「AI練習」にします。

デスクトップ ／ AI練習アプリごとにフォルダーを分けます。

個人情報は、AIに渡さない。
氏名・住所・電話番号・メールアドレス・顔写真など、自分や他人の情報を入力しません。
添付ファイル・スクリーンショット・作業フォルダの中身も対象です。
練習では、架空の名前やデータを使います。

パスワード、APIキー、.env、会社や顧客の資料も、入れたりチャットへ貼ったりしません。

APIキー・.envとは？

APIキーは、外部サービスを使うための秘密の鍵です。.envは、APIキーやパスワードが入ることのある設定ファイルです。サンドボックスを使っても、秘密情報が自動で隠されるわけではありません。

03　Codexを開いて設定する

作業フォルダと作業範囲を選ぶ。

  1. Codexを開きます。
  2. Windowsは Ctrl ＋ O、Macは ⌘ ＋ O を押します。「デスクトップ」→「AI練習」を選んで開きます。
  3. 作業フォルダが「AI練習」になっていることを確認します。
  4. 入力欄の左下から権限メニューを開きます。下の図では「代わりに承認」の部分です。

作業の許可を、どこまでAIに任せるかを選びます。「代わりに承認」では、安全でない可能性があると検出された操作だけ確認が入ります。
練習では、「承認を求める」に切り替えます。

AIが作業できる範囲を制限するのが「サンドボックス」です。「代わりに承認」でも、この制限は残ります。
今回の練習では「フルアクセス」を選びません。

AIに任せる範囲の違い

承認を求める
外部ファイルの編集やインターネットの利用について、常に確認を求めます。

代わりに承認
安全でない可能性があると検出された操作についてのみ確認を求めます。

フルアクセス
インターネットとコンピューター上のすべてのファイルに無制限でアクセスします。

公式の説明

Windowsでサンドボックスの初期設定が出たら

Codexから始めたサンドボックス設定であることを確認し、案内に沿って進めます。初回はWindowsの管理者による許可が必要になることがあります。設定に失敗したら、表示されたエラーを確認します。公式の対処方法

この練習では、Terraを選びます。

05　作業前の説明を指示に入れる

変更内容と外部送信を、先に説明させる。

作業を頼むときは、この文章 (一例です) を指示に入れます。

作業を始める前に、次の2点を短く説明してください。
1. 何を変更するか（対象のファイル・フォルダと変更内容）
2. 外部に送る情報があるか（ある場合は、内容・送信先・目的。なければ「なし」）
途中で予定が変わる場合も、実行する前に説明してください。

次の練習例にある指示文の右上のコピーボタンを押します。
Codexの入力欄へ貼り付け、送信ボタン（↑）を押します。貼り付けは、Windowsなら Ctrl ＋ V、Macなら ⌘ ＋ V です。

最初に出てくる説明を確認し、頼んだ内容と違っていたら止めて訂正します。AIから質問が来たら、同じチャットで答えます。

承認の画面が出たら

事前の説明と同じ作業かを確認し、必要な操作だけ許可します。説明にない変更や外部送信は許可せず、実行前に説明させます。個人情報や秘密情報の送信は許可しません。

途中で止めるときは、停止ボタン（■）。
停止しても、すでに作られたファイルや変更は残ります。続きを頼むときは、同じチャットへ送ります。

    01　まずは相談する

    自分だけで指示を考える必要はありません。

    何を決めるか、どう作るかも、AIと相談できます。まずは欲しいものを伝えて、足りないことはAIに質問してもらいましょう。

    食事代を割り勘するときに、1人あたりの金額が分かる計算機を作りたい。
何を決めればよいか分からないから、まだ作り始めず、私に1つずつ質問して。
難しい言葉を使わず、迷うところは選択肢とおすすめを教えて。
最後に、決まった内容を開発用の指示文にまとめて。
指示文には、変更内容と外部送信の有無を作業前に説明することも入れて。

    右上のコピーボタンを押して、ChatGPTやClaudeの入力欄に貼り付けます。最初の一文を自分の作りたいものに変えて、送ります。

    02　質問に答える

    普段の言葉で答える。

    AI：誰が、どこで使いますか？
    自分だけ。パソコンで使う。
    AI：何を入力して、何を計算したいですか？
    合計金額と人数を入れたら、1人あたりの金額を出してほしい。
    AI：割り切れないときの端数はどうしますか？
    1円単位で切り上げたい。
    AI：人数が0や空欄のときはどうしますか？
    計算せず、入力を直すように注意を出してほしい。

    答えに迷ったら「違いとおすすめを教えて」と聞けば大丈夫です。

    01　変更前の状態を残す

    直す前に、フォルダをコピーする。

    AIの作業が終わり、アプリが動くことを確認してから、デスクトップの「AI練習」を1回クリックします。

    Windows

    Ctrl ＋ C でコピーし、続けて Ctrl ＋ V で貼り付けます。

    Mac

    ⌘ ＋ D で複製します。

    できたコピーを「AI練習_変更前」に名前変更します。Codexでは、元の「AI練習」で作業を続けます。同じ名前のコピーがある場合は、末尾に日付や番号を付けます。

    コミットは、作業の「セーブポイント」。
    Git（変更履歴を残す仕組み）で、ファイルの状態を記録する操作です。動いたところでコミットしておけば、あとでその状態に戻せます。

    普通の「保存」とは別の操作です。戻せるのはコミットに含めたファイルで、記録していない変更やブラウザに保存したデータは含まれません。
